# Zulqarnain Haider — Web Development Month 1

This project contains:

1. A professional personal portfolio.
2. TaskFlow, an advanced to-do and task-management web application.

## Main Features

### Portfolio
- Responsive dark/light interface
- Professional hero and profile presentation
- About, education, skills, projects and experience sections
- Contact links
- Subtle animations and modern responsive layout

### TaskFlow
- Add, edit, delete and complete tasks
- Priority, category and due date
- Search, filtering and sorting
- Progress statistics
- Overdue indicator
- Local Storage persistence
- Responsive dark/light interface

## Run the project

```bash
npm install
npm run dev
```

Open the local address shown in the terminal.

## Production build

```bash
npm run build
```
